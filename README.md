# Daily Dental Care

A modern full-stack web application & CRM for Dental Clinics built with Next.js, React, Tailwind CSS, and Drizzle ORM.

## Features

- 🦷 **Modern Dental Clinic Website**: Patient portal, appointment booking, treatments, before/after gallery, pricing, and contact information.
- 📊 **Comprehensive Dental CRM**: Patient records, appointments schedule, doctor assignments, billing & invoices, inventory management.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- ⚡ **High Performance & SEO Optimized**: Fast server-side and client-side rendering with Next.js App Router.

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/naveenweb0/Daily-Dental-Care-.git
   cd Daily-Dental-Care-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure Environment Variables:
   Copy `.env.example` to `.env` and fill in the required credentials:
   ```bash
   cp .env.example .env
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database / ORM**: Drizzle ORM / PostgreSQL
- **Icons**: Lucide React
